## Rust Code Style

- Always run `cargo fmt` after modifying Rust files.
- Prioritize readability over compactness.
- Separate logically distinct operations with blank lines.
- Group related statements into visual blocks.
- Add blank lines before and after complex control-flow blocks.
- Prefer early returns over deeply nested conditions.
- Use descriptive variable names.
- Avoid excessive one-line expressions and dense method chains.
- Add comments explaining WHY, not restating WHAT the code does.
- Keep functions small and focused on one responsibility.
- Follow idiomatic Rust naming and ownership conventions.
- Do not add blank lines between every statement.
